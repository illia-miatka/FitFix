# EXPERIENCE — FitFix

## Foundation

- Форм-фактор: адаптивний веб, десктоп пріоритетний (файли з годинника зазвичай на компʼютері), мобайл повноцінно підтримується.
- UI-система: власні компоненти на Tailwind з токенами з DESIGN.md. Карта — Leaflet з підкладкою OpenStreetMap, затемненою в CSS (CARTO без ключа віддає водяний знак).
- Мова: українська за замовчуванням. Усі рядки винесено в словник `i18n/uk.ts`.

## Information Architecture

Одна сторінка, три стани:

1. **Upload** — hero «Пробіжка з битим GPS? Полагодимо.», дві Dropzone поруч (на мобайлі одна під одною), CTA «Виправити трек» (неактивна, доки немає обох файлів), блок «Як це працює» з трьох кроків.
2. **Processing** — CTA перетворюється на прогрес-стан, не довше ~1–3 с.
3. **Result** — Hero-картка з дельтами (дистанція, час, темп, пульс) + CTA «Завантажити FIT» → карта + блок попереджень → графік темпу/пульсу із Zone bar → «Почати знову». Disabled-кнопка «Залити у Strava — незабаром».

## Voice and Tone

- Коротко, на «ти». «GPS завис на 22:10 — далі ми розподілили дистанцію рівномірно».
- Помилки: що сталося + що зробити. «Це не схоже на FIT-активність. Спробуй експортувати оригінал зі Strava або Garmin Connect».

## Component Patterns

- **Dropzone:** клік або drag. Під час dragover підсвічує рамку `{colors.accent}`. Після вибору одразу парсить файл на сервері (`/api/inspect`) і показує мета-дані або помилку.
- **Map ↔ Chart sync:** hover або фокус із клавіатури на графіку ставить маркер на карті у відповідну точку. Позиція завжди виражена індексом запису Оригіналу, тому проріджування для рендеру її не зсуває.
- **Layer toggles:** «Оригінал» / «Виправлений» — кнопки з `aria-pressed`, а не декоративні перемикачі.
- **Chart performance:** серії прорідуються перед рендером до ≤ 1000 точок (Recharts малює SVG, і 7200 вузлів дають помітний лаг). Проріджена точка зберігає оригінальний індекс запису.

## State Patterns

| Стан | Що бачить користувач |
| --- | --- |
| Порожньо | Dropzone з підказкою формату |
| Файл парситься | Скелетон у Dropzone |
| Помилка файлу | Червона рамка + текст помилки + «Обрати інший» |
| Обробка | Кнопка зі спінером «Вирівнюю…» |
| Результат з попередженнями | Callout над картою |
| Помилка сервера | Toast «Щось пішло не так» + «Спробувати ще» |

## Interaction Primitives

- Drag-and-drop, клік, клавіатура (Tab/Enter/Space на Dropzone).
- Hover, tap і клавіатура на графіку — три рівноправні способи рухати позицію.

## Accessibility Floor

- Dropzone — `button` з `aria-label`, підтримує клавіатуру.
- Кольори зон дублюються текстом/легендою (не тільки колір).
- `prefers-reduced-motion` вимикає анімації.
- **Карта керується з клавіатури:** стрілки панорамують, є кнопки зуму, маркери старту й фінішу фокусуються, Enter відкриває підпис. Перетягування не може бути єдиним способом рухати карту (WCAG 2.1.1, 2.5.7).
- **Графік керується з клавіатури:** Tab веде на графік, стрілки рухають позицію по точках, фокус показує значення й підсвічує точку на карті так само, як hover. Є перемикач «Таблиця» — той самий ряд даних у вигляді таблиці для тих, кому графік недоступний.
- **Перемикачі шарів — справжні кнопки** з `aria-pressed`, видимим фокусом і підписом, що збігається з видимим текстом. Жодна дія не доступна лише через hover.

## Key Flows

**KF-1 (= UJ-1). Ілля, вечір після пробіжки, ноутбук на кухні.**
1. Відкриває FitFix, бачить дві зони.
2. Тягне `Run_4k_Chabany.fit` → зона показує «19 лис, 36:02, 3,91 км».
3. Тягне `FFF.fit` → «Трек: 6,54 км, 659 точок».
4. «Виправити трек».
5. **Climax:** hero-картка «3,91 → 6,54 км · 9:13 → 5:30 /км», лаймова лінія на карті, жовта смуга на графіку від 28:24 до кінця з підписом «розраховано».
6. «Завантажити FIT» → файл `Run_4k_Chabany_fixed.fit`.

## Inspiration & Anti-patterns

- Inspiration: спортивні прилади, екран результату гонки, мінімалізм Linear.
- Anti-patterns: модалки-візарди на кожен крок, реєстрація перед користю.
